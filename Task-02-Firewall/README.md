# Task 2: Basic Firewall Configuration with UFW

**Objective:** To set up and configure a basic firewall using UFW on Kali Linux to manage network traffic.

### Configuration Rules:
* **Allow SSH (Port 22)**: To ensure secure remote management is possible.
* **Deny HTTP (Port 80)**: To block unauthorized web traffic.

### Included Files:
* `ufw_configuration.sh`: Automation script to apply rules.
* `ufw_status.png`: Screenshot confirming active rules.
* `Task2_Firewall_Demo.mkv`: Video demonstration.
